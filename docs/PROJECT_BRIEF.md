# CentralIA — Project Brief (MVP sans IA)

## Problème
Processus de création/validation de supports lents : allers-retours, corrections répétitives, délais, frustration.

## Solution (MVP)
Plateforme SaaS qui centralise les supports, structure les validations, et facilite la collaboration.
(IA de correction : hors périmètre MVP)

## Cibles
PME, grandes entreprises, agences.

## Modules MVP
- Auth + entreprise (multi-tenant)
- Projets + membres + rôles
- Supports (statuts, types)
- Upload fichiers + versioning
- Commentaires + mentions
- Workflow de validation (valider/refuser/demander modif)
- Historique des actions
